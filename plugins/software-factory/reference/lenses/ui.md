# Lens: ui

Covers what a person sees and does. If the branch has no visible change, write PASS and say so.

Look at it: start the app as AGENTS.md says, in the worktree, on your `Port`, and look at the changed
pages at desktop and phone widths (a browser tool if one is available, otherwise read the rendered
HTML). Don't sign in or submit forms against real services. Stop the app when done.

- **Flow:** it does what the spec promises with no dead ends; loading, empty and error states exist and
  say something useful.
- **Fit:** the same colours, type scale, spacing and components as its neighbours; the existing styling
  system, not one-off CSS or hard-coded colours where a theme value exists.
- **Copy:** short, plain, consistent with the rest of the app.
- **Accessibility:** real buttons and links, labels, focus order, keyboard use, alt text, readable
  contrast.
- **Mobile:** nothing overflows or breaks at phone width.
